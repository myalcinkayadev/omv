# Mic Mute Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Option+M mutes or unmutes the mic from anywhere, with a red mic in the bar while muted.

**Architecture:** Same shape as Night light: a pure module (`micmute.lua`, tested with luajit)
decides what to do; a feature (`features/micmute.lua`) does it with `hs.audiodevice` and
draws the bar item; `init.lua` binds the key. `hs.audiodevice.watcher` takes one callback at
a time and the Sound card already uses it, so both move onto a small shared watcher.

**Tech Stack:** Hammerspoon Lua (luajit for tests), SketchyBar, Python contract tests.

**Spec:** `docs/superpowers/specs/2026-11-13-mic-mute-and-calculator-design.md` (part 1)

## Global Constraints

- Key: Option+M (`SUPER, "m"`); key list group "Tools", description "Mute or unmute the mic".
- Mute the device (`setInputMuted`); when the device refuses, set input volume to 0 and restore it on unmute.
- While muted, a new default input device is muted too.
- Bar: red mic only while muted; a click unmutes. No card.
- Scripting: `omvToggleMic()`, listed with the others in the README.
- Tests named "should <behavior> when <condition>"; luajit for Lua, unittest for the contract.

## Review Focus

1. Hammerspoon reloads while the mic is muted: the device stays muted, so the bar must show it again (read the device on start; for the volume fallback, the level to restore is saved in `~/.local/state/omv/mic`).
2. A Mac with no input device: Option+M alerts "No microphone" and changes nothing.
3. Muted by volume on one device, then unmuted after switching to a device that can mute: the new device unmutes; the old one gets its level back when it's next the default.
4. The Sound card opens and closes while muted: the mic stays muted and device changes are still followed.
5. Unmuting when the saved level is missing: restore to 50%, never leave the mic at 0.

### Task 1: Decide how to mute and unmute (`micmute.lua`)

**Files:**
- Create: `hammerspoon/.hammerspoon/micmute.lua`
- Test: `tests/micmute_test.lua`, `tests/micmute_test.sh` (copy `tests/disk_test.sh`'s shape)

**Interfaces:**
- Produces:
  - `micmute.muting(device) -> { mute = true } | { volume = 0, saved = number }` where `device = { canMute = bool, volume = number }`
  - `micmute.unmuting(device, saved) -> { mute = false } | { volume = number }`
  - `micmute.isMuted(device, savedState) -> bool` where `device = { muted = bool|nil, volume = number }`, `savedState = { uid, volume } | nil`
  - `micmute.encode(state) -> string`, `micmute.decode(text) -> { uid, volume } | nil` (one line: `<uid>\t<volume>`)
  - `micmute.barProperties(muted) -> { string }` (`drawing=on` / `drawing=off`)
  - `micmute.RESTORE_VOLUME = 50`

- [ ] **Step 1: Write the failing tests**
  - should mute the device when it can mute → `muting({canMute=true, volume=70}).mute == true`
  - should set the volume to 0 when the device can't mute → `.volume == 0`
  - should remember the level when muting by volume → `.saved == 70`
  - should unmute the device when it can mute → `unmuting({canMute=true}, nil).mute == false`
  - should restore the saved level when unmuting by volume → `unmuting({canMute=false}, 70).volume == 70`
  - should restore 50% when the saved level is missing → `unmuting({canMute=false}, nil).volume == 50`
  - should restore 50% when the saved level is 0 → `unmuting({canMute=false}, 0).volume == 50`
  - should count a muted device as muted → `isMuted({muted=true, volume=70}, nil)`
  - should count a device at 0 with a saved level as muted after a reload → `isMuted({muted=nil, volume=0}, {uid="x", volume=70})`
  - should not count a device at 0 without a saved level as muted → `not isMuted({muted=nil, volume=0}, nil)`
  - should read back the saved device and level → `decode(encode({uid="BuiltInMicrophoneDevice", volume=70}))` equals both fields
  - should read nothing from an empty file → `decode("") == nil`
  - should draw the bar item only while muted → `barProperties(true)[1] == "drawing=on"`, `barProperties(false)[1] == "drawing=off"`
